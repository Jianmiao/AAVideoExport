# AAVideoExport 0.2.4

Unity 离线音频按混音块输出，视频则按完整画面帧计时。录制结束时可能剩下不足一个音频块的样本；原来固定一帧的容差容易把这种短小的收尾差值判为失败。0.2.4 按输出帧率设置允许差值。

| 输出帧率 | 最大允许差值 | 对应时间 |
|---|---:|---:|
| 24 fps | 2 帧 | 83.33 毫秒 |
| 25 fps | 2 帧 | 80 毫秒 |
| 30 fps | 3 帧 | 100 毫秒 |
| 50 fps | 4 帧 | 80 毫秒 |
| 60 fps | 5 帧 | 83.33 毫秒 |

收尾采样校验与最终文件时长校验共用这套规则。缺少音频或差值超过上限仍停止导出；采样校验另留两个采样点的数值舍入余量。日志保留实际音视频时长、输出帧率、容差帧数和容差秒数。

允许范围内的短缺仍由原有合成步骤在音频末尾补齐，过长的音频仍在视频结束位置裁切；不拉伸语音，不改变画面帧数。容差只检验总时长，不能证明每个语音或音效与画面事件准确对齐。视频帧数、输出帧率和音视频起点校验保持原有要求。

错误状态和设置错误改用红色文字，重试、取消或成功后恢复普通文字颜色。导出期间屏蔽 AA 的点击光效、拖动轨迹和游戏内光标，隐藏开始导出前已出现的鼠标光效；完成或取消后恢复鼠标反馈。保留 0.2.3 的 AUTO 选项修复。

## 安装包

提供小包 `AAVideoExport-0.2.4-win-x64-lite.zip` 和完整版 `AAVideoExport-0.2.4-win-x64-full.zip`。两者 Mod DLL 相同，完整版附带既有 FFmpeg/ffprobe、许可证和来源文件。

退出 AA，将一个包直接解压到 `mods`，目录应为 `mods/AAVideoExport/0.2.4`。在模组管理器选择并启用 0.2.4，按提示重启。旧版目录可以保留，当前 Profile 选择一个 AAVideoExport 版本。

完整版沿用此前发布的独立 FFmpeg 构建，对应资料见 [FFmpeg 源码伴随包](https://github.com/Jianmiao/AAVideoExport/releases/download/v0.2.0/FFmpeg-n8.0-16-gd8605a6b55-source-companion.zip)。

## 验证范围

本次进行编译、容差边界短片及安装包检查。容差检查通过实际编码和音视频合成路径，覆盖各帧率上限、超过上限一帧以及缺失音频；可运行 `VideoExport.Core.Tests --audio-tolerance-only` 重现。鼠标反馈和错误颜色沿用此前本机测试通过的实现，未重新运行整片剧情验收。
