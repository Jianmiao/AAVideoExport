# AAVideoExport 0.2.12

**统一逻辑时间轴 / 单遍音画导出 / 通用 Mod 同步**

发布日期：2026-11-21

0.2.12 是 2026-10-31 冻结的 R2 运行时首次公开发布。它不要求其他 Mod 改代码，也不对每个 Mod 单独写适配；AAVE 用通用的逻辑帧时间、明确的执行/回调顺序和统一的离线媒体机制，把剧情、动画、Mod 特效、语音、BGM 与视频收进同一条时间线。所选剧情只实际播放一次：播放时提交视频帧并连续记录 Unity 原生离线 PCM，完成后按实际剧情终点封存音频、排空有界 GPU/编码队列并合成电影。

## 本版内容

- 生产构建默认单遍导出，不再为生成电影重放第二遍剧情。
- 原生 AUTO、Mod 回调、局部起始偏移、增益、渐变、循环与语音等待保持原有行为；资源未就绪时先等待，不提前推进剧情帧。
- 保留原生 BGM 生命周期、取消清理、场景恢复和有界 GPU 读回/编码流水线。
- 公开 `RenderControlV1` v1：导出期间交接渲染设置，退出后恢复普通 AA/Mod 行为；不要求修改 Azurite 白名单或覆盖其文件。
- 普通包不含开发审计 bootstrap、测试插件或重复基线；正常启动会清除继承的 AAVE 测试/审计环境变量。

## 实际验收

冻结 R2 在真实 AA 1.0.1 / BepInEx 6 IL2CPP / 实际安装的 Azurite 环境中完成取消与重复导出 8/8：

| 项 | 结果 |
|---|---|
| 完整导出 | 2 份，各 453 帧 / 15.1 秒 |
| 原生音频 | 每份 724800 个 48 kHz 采样帧，2 声道 PCM16 |
| 取消 | 1 次，12 帧后取消并完成恢复 |
| Azurite RenderControlV1 | 3/3 次取得/释放，8/8 路径检查通过 |
| PCM 对比 | `MaximumErrorLsb=0.5`，`MismatchedSamples=0` |
| 发布身份 | Plugin `47DF9237…`，Core `F728E74D…` |

实际安装 DLL 与冻结发布 DLL 哈希一致；成片用 ffprobe 复核为 H.264 640×360、453 帧、15.1 秒、PCM16 48 kHz 2 声道 724800 采样。原始画面存在 35 个像素观测差异、最大每通道 1/255，全部受限于动态字形图集三角形；字体外像素完全一致，最终解码画面一致，没有扩大遮罩或放宽全画面阈值。

## 安装

1. 完整退出 AA。下载 `full` 或 `lite` bundle，解压到独立目录；不要直接把整个 bundle 解压进 `mods`。
2. 用 PowerShell 7.2+ 运行：
   ```powershell
   pwsh -NoProfile -File .\Install-Mod.ps1 -AAInstallPath '你的 AA 安装目录'
   ```
   可先加 `-PlanOnly` 查看只读计划。安装器会校验包内哈希、程序集版本、生产/审计模式与当前 Profile，只创建 `mods/AAVideoExport/0.2.12` 并切换当前 Profile 的 AAVE 选择。
3. 双击 AA 根目录的 `Start-AA-AAVE-0.2.12.cmd`，或在 PowerShell 7 运行 `Start-AA-AAVE-0.2.12.ps1`。
4. 在鉴赏模式选择剧情，使用导出入口或 `Ctrl+Shift+E` 打开设置；先运行真实编码器检测，再选择输出目录与参数。

`full` 包含 FFmpeg/ffprobe 与许可证；`lite` 使用你已安装/配置的编码器。Plugin/Core 必须来自同一发布包。

## 回滚

退出 AA，使用安装器输出的准确回执路径：

```powershell
pwsh -NoProfile -File .\Rollback-AA-AAVE-0.2.12.ps1 -ReceiptPath "安装器输出的 install-receipt.json 完整路径"
```

## 边界

- 验收只覆盖对应冻结二进制、固定主机、固定 Mod 组合、固定剧情和指定输出设置；不是任意机器、任意 Mod、任意编码器的全面兼容保证。

- 发布包不包含 AA 本体、原生宿主程序集、个人作品、配置或测试插件。
