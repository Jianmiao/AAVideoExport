# 0.2.0 发布验证

## 安装包

小包 `AAVideoExport-0.2.0-win-x64-lite.zip` 不含编码器；大包 `AAVideoExport-0.2.0-win-x64-full.zip` 附带 FFmpeg/ffprobe。两者都只有 `AAVideoExport/0.2.0/` 这一目录前缀，直接解压到 AA 本体的 `mods` 文件夹。模组管理器中选择并启用 0.2.0；升级时旧版本可保留。

两个 ZIP 包含完全相同的 Mod DLL、图形依赖及模组说明，各包均附带适用许可证与覆盖自身内容的完整校验和。只有大包额外附带编码器并自动从模组目录查找；小包使用环境中的工具。旧配置中明确指定的路径仍优先。AA、BepInEx、interop、作品资源、Profile 和测试插件不在包内。

## 本轮验证结果

- .NET Release 构建：0 警告，0 错误。
- 20 组可移植功能检查，共 248 项通过；不启动 AA。
- 预编译版本目录、manifest、插件程序集 0.2.0.0 及 11 个运行文件校验通过。
- 两个 ZIP 分别检查路径、完整校验和、真实 PE 二进制及排除项；小包禁止包含编码器，大包要求两个编码程序及许可证齐全。
- FFmpeg 与 ffprobe 使用 BtbN 固定 n8.0-16-gd8605a6b55 构建，核对上游 SHA-256；检查实际版本、配置、滤镜、编码器和硬件接口。
- 使用包内工具生成并读取 0.5 秒、320×180、30 FPS 的合成片段：15 帧 QSV H.264 + AAC，ffprobe 可正常读取。
- 公开 RenderControlV1 ABI 检查通过。生命周期回归覆盖接管前通知、快照顺序、嵌套持有、取消、异常恢复和关闭。

这些检查不等于完整 AA 剧情成片、三家显卡全型号或视觉效果验收，不承诺特定速度提升。
