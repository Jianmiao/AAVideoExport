# AAVideoExport 首次公开仓库交付

## 发布内容

- 发布当前 `0.1.0` 单页设置版，构建标记 `20261003-unified-settings-accordion`。
- 根目录 `0.1.0/` 含 11 个运行文件：两个 Mod DLL、七个图形依赖 DLL、manifest 与自制图标。用户在 AA 的 `mods` 目录克隆即可得到正确布局，再在 AA 启用。
- 保留 Core / Plugin 生产源码、功能测试、明确 opt-in 的原生验收夹具、构建与打包工具、第三方声明。
- README 说明安装、更新、FFmpeg 依赖、使用方式、当前功能和验证范围。
- 本次发布整理不修改生产渲染逻辑，也不替换此前已验收的运行 DLL。45 个生产源文件与当前本地单页版相同。

## 验证

- 公共源码副本构建：0 警告、0 错误；原生测试夹具也可独立构建。
- 纯功能回归：17 组，206 项通过，0 失败；不启动 AA，不运行性能测试。
- 克隆安装校验：检查版本与路径、11 个文件 SHA-256、9 个真实 PE DLL、声明文件；不接受 Git LFS 指针作为 DLL。
- 工作副本不包含 AA 程序、游戏数据库或素材、个人工程、Profile、凭据、interop、测试产物和历史备份。
- 已验收的单页版原生 UI 证据包含三组：单页与无标签、展开/收起及输入保留、窗口比例与 720P 超分。它们是本次发布前同一运行 DLL 的本机验证，不能冒充远程 CI 的原生验收。
- CI 执行克隆结构校验和纯功能测试，不需要 AA 本体或显卡媒体测试。

## 兼容与边界

仍使用原有插件 ID、版本号、Profile 配置和路径记忆，发布不更改用户现有 AA 安装。
已有手工安装用户须先将同名文件夹移到 `mods` 外备份；不要覆盖或叠套克隆目录。
未来克隆安装使用 `git pull --ff-only` 更新。

AA、BepInEx、ModTheAzureArchive、FFmpeg/ffprobe 和驱动是外部前提；克隆不安装这些宿主组件。
没有新增跨 GPU 性能承诺，四槽 D3D 读回仍属默认关闭的实验选项。
保留研究文件来源与单独许可边界，不能将该文件自动重新授权为本仓库 MIT；见第三方声明。
