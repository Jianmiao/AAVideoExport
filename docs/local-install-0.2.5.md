# AAVideoExport 0.2.5 本地测试版

构建标识：`0.2.5-local-timeline`。本版基于本地 0.2.4 源码及本次获准的方案 1 改动，未提交或发布。

安装目标为 `F:\AzureArchive_101\mods\AAVideoExport\0.2.5`，保留原有 `0.2.4` 以供回退。清单、BepInEx 插件版本及两个 AAVE 程序集均使用 0.2.5；公开 RenderControlV1 协议仍为 1。

本地构建包含有理数音频采样预算、逐帧音频入口、视频包时间戳与容器时间基检查，以及本轮 CBR 参数修改。附带原完整版的 FFmpeg、ffprobe 和第三方许可资料。

本版已进行构建、自动化及合成媒体检查，尚未完成 AA 原生剧情重复导出验收。Unity 混音块不一定逐帧等于理论采样预算，当前严格校验可能拒绝这种输出。现有结果不能证明每次真实剧情的总帧数、平均码率或字节完全相同，也不能证明所有画面事件与语音已经对齐。

启动 AA 后在模组管理器的当前 Profile 中选择并启用 AAVideoExport 0.2.5，按提示重启；每个 Profile 只选择一个 AAVE 版本。如需回退，改选保留的 0.2.4 并重启。安装不更改其他 Mod 或个人工程。
