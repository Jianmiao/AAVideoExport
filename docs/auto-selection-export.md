# AUTO 选项导出修复（0.2.3）

基于 GitHub `main` 的 `5c4794e0c11b4220b438ffd0683ddcb2095c16ef`，使用新版 AA 1.0.0-fix 的宿主接口构建。本版没有修改导出帧率或采样方式。

## 问题和处理

AA 的自动选择倒计时和按钮提交是两个步骤。如果倒计时结束，而按钮模拟点击没有进入选项回调，剧情会停留在选项界面。导出任务仍等待原生剧情结束，因此可能持续录制重复画面。

导出期间沿用 AA 的原生 AUTO 倒计时和作者标记的默认分支。在匹配当前剧情、选项管理器和默认选项的前提下，自动按钮协程直接调用原生 `SelectionElement.OnSelect()`，不等待模拟按下/松开按钮。在倒计时结束后再次检查同一选项，补交未成功提交的 AUTO 选项。原生选项退出动画、回调和剧情分支保持由 AA 执行；同一选项不会重复提交。创建新选项时重置提交状态。

没有标记有效 AUTO 分支时停止导出，提示作者设置 AUTO；不自行选择第一项。提交失败或选项接口无法绑定时也停止并清理导出状态。所有选项适配在未导出、导出取消或完成后均不接管普通播放。

这是针对录制停留的保护。不能仅凭时长变化断定所有“10 分钟变成 20 分钟”的反馈都由选项引起。

## 验证

- 选择测试链接生产的适配和 Harmony 钩子，覆盖倒计时、按钮路径、漏提交补交、重复提交、过期选项、非 AUTO 按钮、普通播放、报错和新选项状态重置。
- 宿主测试链接真实 `ExportHost`，覆盖缺少 AUTO 时的停止、资源恢复及提交错误处理；音频和导出时钟回归测试也通过。
- 原生隔离测试使用最新 AA 的真实选项 UI、AUTO 协程和导出捕获设置。故障注入只阻断模拟点击：修复前倒计时已经结束，经过 300 帧（10 秒剧情时间）仍无分支回调；修复后进入标记的分支，选项提交和回调各执行一次。
- 原生 A1 默认选项测试确认进入第二项的分支，未选择 A0；原生未标记 AUTO 的测试得到明确的 `selection_default_missing` 错误，没有提交任何分支。
- 2026-10-05，本地用户在新版 AA 中安装选项修复后反馈使用无问题；据此将本修复升级为 0.2.3。

原生实验使用隔离副本和合成两选项测试，不加载用户作品。上述实验验证特定故障路径和保护逻辑，不等同于复现用户反馈的完整长视频，也不代表已完成其整片音画同步验收。

## 本机构建

```powershell
dotnet build src/VideoExport.Plugin/VideoExport.Plugin.csproj -c Release '-p:AAInstallPath=你的新版 AA 路径'
dotnet run --project tests/VideoExport.Selection.Tests -c Release '-p:AAInstallPath=你的新版 AA 路径'
dotnet run --project tests/VideoExport.Host.Tests -c Release
```

没有 SDK 的环境可用仓库现有 `tools/Build-Offline.ps1`，传入本地 Roslyn、.NET 6 runtime 和最新 AA 接口路径。离线构建现在包含 Selection 回归测试。
