# AAVideoExport 0.2.3

修复新版 AA 中 AUTO 选项停留导致导出继续录制的问题。2026-10-05，本地用户安装选项修复后反馈使用无问题，版本按维护者要求升级为 0.2.3。

## 行为

AA 的 AUTO 倒计时结束后，模拟按钮点击有可能未完成选项提交。此时剧情未结束，导出仍会继续保存选项界面的帧。0.2.3 在导出期间直接提交当前作品标记的 AUTO 选项，并在倒计时结束后补交尚未提交的同一选项；同一选项最多提交一次。

保留原生倒计时、选项退出动画和剧情回调。没有有效 AUTO 默认选项时停止并提示设置，不擅自选择第一项。提交失败或接口不兼容时停止并恢复导出状态。适配不接管普通播放，取消或完成后释放选择状态。

导出帧率、采样方式、编码选择、音频混音和 `RenderControlV1` 接口沿用此前版本。已有的 CPU 编码和工作区路径修复继续保留。

## 安装

- 小包：`AAVideoExport-0.2.3-win-x64-lite.zip`，需要可用的外部 FFmpeg/ffprobe。
- 完整包：`AAVideoExport-0.2.3-win-x64-full.zip`，附带与此前 Release 相同的 FFmpeg/ffprobe、许可证和来源说明。

退出 AA，将一个包直接解压到 `mods`，目录应为 `mods/AAVideoExport/0.2.3`，在模组管理器选择并启用 0.2.3 后重启。旧版目录可以保留，但当前 Profile 只选择一个 AAVideoExport 版本。完整包默认从自身 `tools` 目录寻找编码器；已有明确指定的工具路径仍优先使用。

完整版沿用此前已发布的独立 FFmpeg 构建。对应源码资料仍位于 [FFmpeg 源码伴随包](https://github.com/Jianmiao/AAVideoExport/releases/download/v0.2.0/FFmpeg-n8.0-16-gd8605a6b55-source-companion.zip)。

## 验证范围

选择适配 9 项、宿主生命周期 18 项、捕获/音频恢复 30 项、导出时钟 11 项回归检查通过。最新 AA 原生隔离测试覆盖模拟点击失效后的补交、A1 被标为默认选项、未标记 AUTO 时的停止提示；本地用户随后确认实际使用无问题。

详细机制及测试边界见 [AUTO 导出适配](auto-selection-export.md)。这些验证不意味着所有超长视频问题都由选项引起，也不代表所有作品完成了整片音画同步验收。
