# AAVE research source checkpoint — 2026-11-15

This is a small archive of selected authored source and controls from four sealed research checkpoints: CompletionFacts, PreviewReuseR6, ActivityOutputR5 and EmitterFlagsR4. It preserves useful implementation work and its verification boundaries. It is not a stable release, installable Mod, complete source distribution, or independently buildable package.

The original source layout is retained below this archive directory. Build descriptors may contain fixed development paths and links to other sealed source trees that are intentionally absent. They also reference externally supplied Harmony, MonoMod, Cecil, host bindings and earlier test components. The optional private `local.props` is not included. R5 additionally needs its earlier recovery modules, observer/driver and controlled scene package, which are not in this archive. Adaptation requires a separate coherent dependency/build review; running a source file from this archive is not an approved AA execution procedure.

Only source, control programs, original project/build descriptors, an interface description, and existing license notices are selected. There are no AA/Mod/Unity/interop or third-party DLLs, executable packages, generated binaries, raw logs, registry snapshots, personal media, story saves, credentials, decompiled input bodies, or large evidence trees. The separately sourced Il2CppBulkCopy research contribution with unspecified independent licensing is excluded. Existing LICENSE and THIRD_PARTY_NOTICES retain their original scope; this archive creates no additional third-party license grant.

Validation tiers are summarized separately in VERIFICATION-SUMMARY.md. Ordinary controlled results, independent source review, bounded normal-provider experiments and actual AA operation are distinct. The latter is not established by this archive. Historical failures remain part of the locally retained evidence, and successful later controls do not erase them. The public RenderControlV1 compatibility obligation and all remaining production integration, native ownership and release gates continue to apply.
